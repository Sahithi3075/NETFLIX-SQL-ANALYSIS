# NETFLIX-SQL-ANALYSIS
# 🎬 Netflix Content Analysis using SQL

## 📌 Project Overview
This project analyses the Netflix Movies and TV Shows dataset using SQL to uncover trends in content, genres, countries, ratings, and release patterns.

## 🛠️ Tools Used
- SQL (MySQL)
- Netflix Dataset

## 📂 Dataset
- netflix_titles.csv

## 📊 SQL Concepts Used
- SELECT
- WHERE
- GROUP BY
- ORDER BY
- CASE WHEN
- Aggregate Functions
- JOINs (if applicable)
- Subqueries

## 📈 Business Questions Solved
- Total number of Movies vs TV Shows
- Most common content ratings
- Top countries producing Netflix content
- Year-wise content additions
- Longest movies
- Most popular genres
- Directors with the highest number of titles

## 📁 Files
- NETFLIX-SQL-ANALYSIS.sql
- netflix_titles.csv

## 💡 Key Insights
- Movies make up the majority of Netflix content.
- The United States contributes the highest number of titles.
- Drama and International Movies are among the most common genres.
- Content additions increased significantly after 2015.
